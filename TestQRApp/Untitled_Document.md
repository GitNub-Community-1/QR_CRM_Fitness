# ⚡ FitPass CRM — Система управления фитнес-клубом и контроля доступа

## FitPass CRM — это веб-приложение на базе .NET / Blazor Server, предназначенное для автоматизации работы фитнес-клубов. Система обеспечивает удобный учет клиентов, управление абонементами, сканирование QR-кодов/карт на входе, а также мониторинг посещаемости и загрузки зала в реальном времени.
### 🚀 Основной функционал
1. 🛡️ Дашборд Модератора / Администратора

    Статистика в реальном времени:

        Загрузка зала (посещения за последние 3 часа).

        Общее количество визитов за текущий день.

        Количество зарегистрированных новых клиентов за текущий месяц.

    Автоматическая «Лента входов»: отображает последние попытки входа (успешные / отказы) с таймером автообновления через Blazor Server.

    Управление базой клиентов:

        Быстрый поиск по ФИО, номеру телефона или логину.

        Пагинация списка клиентов.

        Просмотр полной карточки клиента.

        Привязка и продление тарифных планов (абонементов).

        Сброс привязанного устройства (ActiveDeviceId).

### 2. 🎛️ Система контроля доступа (Сканер Входа)

    Мультирежимная проверка пропусков:

        Веб-камера (сканирование QR-кодов с экрана смартфона или распечатанных карт).

        Загрузка изображения/скриншота QR-кода.

        Ручной ввод ID или работа через подключенный USB-сканер штрихкодов/QR.

    Автоматическая валидация:

        Проверка наличия и активности абонемента.

        Проверка остатка доступных посещений и срока действия.

        Отображение мгновенного статуса (ДОСТУП РАЗРЕШЕН / ДОСТУП ЗАПРЕЩЕН).

### 3. 👥 Управление персоналом и клиентами

    Регистрация клиентов: добавление личных данных, привязка персонального тренера при необходимости.

    Управление тренерами и тарифами: настройки типов абонементов (цена, длительность, лимит посещений).

### 🛠️ Технологический стек

    Framework: .NET 8 / Blazor Server (InteractiveServer)

    UI & Styling: HTML5, CSS3, Bootstrap 5, Bootstrap Icons

    Database & ORM: Entity Framework Core / SQL Server

    Authentication & Authorization: ASP.NET Core Identity / Cookie Authentication с поддержкой ролей (Admin, Moderator)

    Libraries: ZXing.Net / JS Interop (для сканирования QR-кодов)

### 🔧 Архитектура сервисов (Dependency Injection)

Приложение построено на основе сервисно-ориентированной архитектуры с чётким разделением ответственности:

    IAccessControlService — отвечает за обработку попыток входа, валидацию статуса абонемента и сохранение записи в AccessLogs.

    IAnalytickcService — агрегирует аналитику: рассчитывает текущее количество людей в зале, количество визитов за день и формирует ленту последних проходов.

    IClientManagerService — выполняет CRUD-операции над клиентами, а также логику привязки и продления абонементов.

    IAuthService — отвечает за аутентификацию, управление ролями и сброс идентификаторов устройств (ActiveDeviceId).

    IQrCodeService — генерация QR-кодов для клиентов и их декодирование.

    ISubscriptionTypeService — управление тарифной сеткой клуба.

### ⚙️ Установка и запуск
Предварительные требования

    .NET 8.0 SDK

    SQL Server / LocalDB

### Шаги по запускy:

    Клонируйте репозиторий:
    Bash

    git clone https://github.com/your-username/TestQRApp.git
    cd TestQRApp

    Настройте строку подключения:
    Откройте appsettings.json и укажите параметры подключения к вашей базе данных SQL Server:
    JSON

    "ConnectionStrings": {
      "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=FitPassDb;Trusted_Connection=True;MultipleActiveResultSets=true"
    }

    Примените миграции:
    Bash

    dotnet ef database update

    Запустите проект:
    Bash

    dotnet run

    Откройте браузер и перейдите по адресу: https://localhost:7190 (или порту, указанному в консоли).

### 🔐 Роли по умолчанию

    Admin — полный доступ ко всем разделам системы, управлению персоналом и аналитике.

    Moderator — доступ к ресепшену, сканеру входа, базе клиентов и назначению абонементов.
